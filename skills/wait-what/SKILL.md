# Wait What

## Procedure

1. Stop the current thread of explanation and restate the topic in one sentence.
2. Add the minimum missing context needed to make the next step legible.
3. Re-pitch with short direct sentences and the established project vocabulary from `GLOSSARY.md` when one exists.
4. If ambiguity remains, ask one concrete check question instead of continuing the old explanation.
